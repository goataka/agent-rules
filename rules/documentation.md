# ドキュメントルール

- 言語：原則として日本語
- 表現：簡潔にし、基本は箇条書きとする
- 形式：可能な場合は「項目：値」とし、段落にはタイトルを付ける
- 強調：重要な単語は**太字**にし、可能な場合はリンクを設置する
- 構成：長くなる場合はページを分け、目次を設定する
- 括弧：（）は極力使わない
- 改行：「。」で文を終えたら別の行にする
- 重複：同じ内容を複数の文書に書かず、1か所に書いてリンクする
- 決定の記録：方針や仕様を決めたときは、決定、理由、選ばなかった案を1つの決定につき1ファイルで残す
- 派生データ：一次資料を正とし、そこから作った文書やデータには生成元を書く
