# エージェントルール

作業内容に応じて、該当するルールを**必ず参照**し、従う。

## 参照先

- **コーディング**：[コーディングルール](coding.md)
  - 対象：コードの作成・修正・レビュー
- **Shell**：[Shellルール](shell.md)
  - 対象：シェルスクリプトの作成・修正
- **テスト**：[テストルール](test.md)
  - 対象：テストコードの作成・修正
- **ドキュメント**：[ドキュメントルール](documentation.md)
  - 対象：ドキュメントの作成・修正
- **応答**：[応答ルール](response.md)
  - 対象：ユーザーへの応答（常に適用）

## 運用

- 適用：複数のルールに該当する場合は、すべてに従う
- 優先：リポジトリ固有のルールがある場合は、そちらを優先する
